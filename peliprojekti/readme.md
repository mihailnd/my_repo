# Escape From Hylätty Tehdas

## Pelin idea
Escape From Hylätty Tehdas on Pythonilla tehty tekstiseikkailupeli. Pelaajan pitää tutkia hylättyä tehdasta, kerätä esineitä, suorittaa ympäristöystävällisiä tekoja ja löytää tie ulos.

## Pelin ominaisuudet
- Huoneiden tutkiminen
- Esineiden kerääminen
- Kolme erilaista pakoreittiä
- Ympäristötekojen tekeminen

## Käynnistäminen
Käynnistä peli komennolla:

```bash
python peli.py
```

## Tiedostot
- `peli.py` – pelin päätiedosto
- `funktiot.py` – pelin funktiot
- `luokat.py` – pelin luokat
- `ohjeet.txt` – ohjeet peliin
